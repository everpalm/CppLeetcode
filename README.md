# CppLeetcode

Leetcode practice with Cpp

## Introduction

This project contains solutions to various Leetcode problems implemented in C++. It serves as a practice ground for improving problem-solving skills and understanding C++ programming concepts.

## Installation

To set up this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone [repository-url]
   ```
2. Navigate to the project directory:
   ```bash
   cd CppLeetcode
   ```
3. Build the project using CMake:
   ```bash
   cmake .
   make
   ```

## Usage

To run a specific solution, navigate to the corresponding directory and execute the compiled binary. For example, to run the solution for `rotate_array`:

```bash
cd Array\ and\ String
./rotate_array
```
